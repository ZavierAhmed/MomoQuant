# Milestone 23.0E2B1 Integration Database Isolation

- The accidental one-time application of the nullable E2B columns to the normal local database is retained; no rollback is performed.
- Integration tests must use the centralized resolver and target databases whose names end with `_test`.
- Integration tests never fall back to the application's `DefaultConnection`.
- API and Worker `DatabaseMigrations:ApplyOnStartup` settings default to `false`.
- Local `*.local.env` files are ignored by Git.
- Future operators must apply migrations deliberately with `dotnet ef` or an explicit startup opt-in.
